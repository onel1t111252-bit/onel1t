# C++ Console Toolkit

A beginner-friendly C++17 command-line project demonstrating arrays/vectors, matrix loops, algorithms, input validation, and a menu-driven console interface.

## Features
- Analyze numeric values (minimum, maximum, average)
- Print a numbered matrix
- Sort numeric values
- Basic validation for input sizes

## Build and run
```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o toolkit
./toolkit
```
On Windows, run `toolkit.exe` after compiling with MinGW or another C++17 compiler.

Educational project only; it does not access networks or modify files.
