CASE STUDY / DEFENSIVE SECURITY PRODUCT

ONEL1T AEGIS

A local-first security operations simulation designed to connect incident triage, asset context, risk decisions, response playbooks and analyst reporting without touching live systems or external targets.

OPEN PLATFORM ↗SOURCE ↗
01 / PROBLEM

Security learning is often fragmented.

Logs, assets, risks, response steps and reports are commonly studied as separate topics. The project goal was to turn those concepts into one coherent defensive workflow.

02 / SOLUTION

One connected analyst workspace.

AEGIS presents synthetic incidents alongside the affected asset, risk context, playbook steps and reporting state so that each analyst action has visible context.

03 / WORKFLOW

Observe → Context → Decide → Record

01Observe

Synthetic alerts enter the local queue.

02Context

Review asset ownership, controls and criticality.

03Decide

Prioritize, triage and select a safe response path.

04Record

Track status, playbook progress and analyst summary.

04 / MODULES

What is included

  • Operations overview and posture metrics
  • Synthetic incident queue and triage state
  • Asset inventory and defensive controls
  • Risk register and treatment decisions
  • Interactive defensive playbooks
  • Drill scenarios and text-report export
  • EN / UA / CZ interface
05 / SAFETY

Designed as a safe lab.

AEGIS does not scan networks, exploit systems, collect credentials or interact with external targets. The data is synthetic and the project runs locally in the browser.

07 / SIGNAL

What it demonstrates

Defensive-security thinking, information architecture, incident workflow design, state management, responsive frontend engineering and the ability to turn cybersecurity coursework into a cohesive product.
