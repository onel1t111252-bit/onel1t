Security Log
Triage Lab

Practice blue-team investigation with sample authentication logs. The analyzer looks for failed logins, invalid users, accepted sessions, privilege escalation and repeated activity, then groups matching events into a quick triage report.

Load the sample logs or paste sanitized log lines, then analyze.

Privacy: log parsing is performed locally in your browser; content is not uploaded. Remove real usernames, public IPs, tokens and other sensitive details before using any log-analysis tool. This is a learning aid, not a SIEM or incident-response verdict.
