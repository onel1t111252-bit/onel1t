# ONEL1T Cyber Lab

A standalone browser-based cybersecurity learning platform hosted as a separate project from the main CV site.

## Modules
- SOC Simulator with fictional incident scenarios and triage feedback
- Network Visualizer with an interactive topology sandbox
- Rule-based Security Assistant demo
- Cyber Academy lessons and quiz
- Local password-characteristics checker
- Phishing URL pattern analyzer
- Progress tracking via browser localStorage and TXT report export

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Important
This is an educational demo. SOC logs and network connections are simulated. The assistant is rule-based and is not connected to an AI API. URL analysis uses local heuristics and is not a reputation or malware verdict. Do not enter real passwords.

The project is located at `/projects/cyber-lab/` in the ONEL1T GitHub Pages repository.
